BPE 학습: 가장 자주 붙는 쌍을
합치고, 그 순서를 기록합니다

① 단어를 글자로 쪼갠다 → ② 인접 쌍의 빈도를 단어 빈도만큼 더해 센다 → ③ 가장 많은 쌍을 새 토큰으로 합친다 → ④ 정한 어휘 크기까지 반복.

학습의 결과물은 어휘와 병합 규칙의 순서입니다.

초기 말뭉치low ×5 lower ×2 newest ×6 widest ×3
규칙병합빈도 계산병합 후 바뀐 단어
1e + s → esnewest 6 + widest 3 = 9newest widest
2es + t → est6 + 3 = 9newest widest
3l + o → lolow 5 + lower 2 = 7low lower
4lo + w → low5 + 2 = 7low lower

동점: 1단계 e+s = s+t = 9, 3단계 l+o = o+w = 7 → 먼저 센 쌍을 고르는 구현 규칙으로 결정
Python Counter.most_common과 Node 재구현에서 같은 순서 확인 · 알고리즘: Sennrich 2016 Algorithm 1

근거: Sennrich et al. 2016 · §3.2 · Algorithm 1
글자로 쪼개고, 가장 자주 붙는 쌍을 합쳐 새 토큰으로 어휘에 넣고, 다시 세서 반복합니다. 정한 어휘 크기, LLaMA는 32,000개가 될 때까지 합니다. 중요한 건 합친 순서가 곧 규칙이라는 점입니다. 동점이 두 번 나오는데, 이건 구현이 먼저 센 쌍을 고르기 때문에 정해진 것입니다. (3분 · 중심 슬라이드, 화이트보드로 1단계 빈도를 직접 세어 보여 주기)

Byte Fallback: 어휘에 없는 글자는
UTF-8 바이트로 쪼갭니다

모든 글자는 UTF-8로 1–4바이트입니다(영어 1, 한글 음절 3, 이모지 4). 바이트 값은 256가지뿐이라 <0x00>…<0xFF>를 어휘에 넣어 두면 어떤 글자도 표현되고 <unk>가 생기지 않습니다.

대가는 길이입니다. 어휘에 없는 한글 음절 하나가 토큰 3개가 됩니다.

BPE 병합과는 별개 규칙입니다. 병합은 자주 나오는 조각을 만들고, byte fallback은 어휘 밖 글자를 처리합니다.

근거: LLaMA 1 v1 · §2.1 · SentencePiece · Kudo & Richardson 2018 · W01 덱 · Tokenizer
어휘에 없는 글자는 <unk> 대신 UTF-8 바이트로 쪼갭니다. 바이트 토큰 256개를 어휘에 미리 넣어 두면 어떤 글자도 표현됩니다. 대가는 길이입니다. 한글 음절이 어휘에 없으면 토큰 3개가 됩니다. (W01 덱은 LLaMA 어휘의 한 음절 한글 토큰이 111개라고 보고했습니다. 이 수치는 제가 재현하지 않았으니 “W01 덱에 따르면”이라고 말합니다.) (2분)

장난감 BPE와 실제 tokenizer

1단계는 BPE 원리를 구현해 슬라이드 4와 같은 순서가 나오는지 봅니다. 2단계는 이미 학습된 LLaMA tokenizer를 불러와 실물을 관찰합니다. huggyllama/llama-7b는 LLaMA 1 재배포본이고, Llama 2는 원문상 같은 tokenizer입니다.

1단계 · 장난감 BPE 원리

corpus = {"l o w": 5, "l o w e r": 2,
          "n e w e s t": 6, "w i d e s t": 3}
merges = []
for step in range(4):                # 학습
    pair, freq = pair_counts(corpus).most_common(1)[0]
    merges.append(pair)              # 순서 = 규칙
    corpus = merge(corpus, pair)
def encode(word):                    # 적용
    sym = list(word)
    for a, b in merges:              # 배운 순서대로
        sym = merge_pair(sym, a, b)
    return sym
merges = [('e','s'), ('es','t'), ('l','o'), ('lo','w')]
encode("lowest") → ['low', 'est']

어휘만 256k → 32k
